
# HANAN Flower Classifier 🌸

Welcome to HANAN Flower Classifier!

This is an Artificial Intelligence application
that identifies different types of flowers from images.

## Technologies Used
- Python
- Streamlit
- TensorFlow
- NumPy
- Pillow

## Flower Categories
- Roses
- Sunflowers
- Daisies
- Tulips
- Dandelions

## How to Run

pip install -r requirements.txt

streamlit run streamlit_app.py
